# Data Model

All data stored by the Real3D Flipbook WooCommerce Addon.

## Product Meta (post_meta on `product` post type)

### `r3d_flipbook_id`

| Property  | Value                                            |
| --------- | ------------------------------------------------ |
| Type      | `string` (numeric ID or semicolon-separated IDs) |
| Default   | Empty string (not set)                           |
| Stored on | `product` post type                              |

The flipbook ID shown to users who have purchased the product. Can contain multiple IDs separated by semicolons (e.g., `"12;34;56"`). The first ID is used for the product page display; all IDs appear in the My Account purchased flipbooks tab.

When empty or not set, no flipbook is shown to purchasers.

### `r3d_preview_flipbook_id`

| Property  | Value                  |
| --------- | ---------------------- |
| Type      | `string` (numeric ID)  |
| Default   | Empty string (not set) |
| Stored on | `product` post type    |

The flipbook ID shown to users who have **not** purchased the product. Typically a limited-page preview version. Only the first ID is used (parsed via `get_first_flipbook_id()`).

### `r3d_show_thankyou_flipbook`

| Property  | Value                                       |
| --------- | ------------------------------------------- |
| Type      | `string` — one of `"yes"`, `"no"`, or empty |
| Default   | Empty string (use global setting)           |
| Stored on | `product` post type                         |

Per-product override for thank-you page flipbook display:

| Value                | Behavior                                                                                           |
| -------------------- | -------------------------------------------------------------------------------------------------- |
| `"yes"`              | Always show the flipbook on the thank-you page for this product, regardless of the global setting. |
| `"no"`               | Never show the flipbook on the thank-you page for this product, regardless of the global setting.  |
| `""` (empty/not set) | Follow the global setting (`r3d_woo_show_thankyou_flipbook` option).                               |

## Variation Meta (post_meta on `product_variation` post type)

### `_flipbook`

| Property  | Value                         |
| --------- | ----------------------------- |
| Type      | `string` — `"yes"` or `"no"`  |
| Default   | Not set (treated as enabled)  |
| Stored on | `product_variation` post type |

Controls whether a specific variation grants flipbook access when purchased. Displayed as a checkbox ("Flipbook") in the variation options panel next to "Manage stock."

| Value              | Behavior                                                      |
| ------------------ | ------------------------------------------------------------- |
| `"yes"` or not set | Purchasing this variation grants flipbook access.             |
| `"no"`             | Purchasing this variation does **not** grant flipbook access. |

Variation-level `r3d_flipbook_id` is also checked — if a variation has its own `r3d_flipbook_id`, that ID is used instead of the parent product's.

## Options (wp_options table)

### `r3d_woo_show_thankyou_flipbook`

| Property | Value                             |
| -------- | --------------------------------- |
| Type     | `bool` (stored as `"1"` or `"0"`) |
| Default  | `false`                           |

Global setting that controls whether flipbooks are displayed on the WooCommerce order thank-you page. Can be overridden per-product via `r3d_show_thankyou_flipbook` post meta.

## Transients

### `r3d_purchased_flipbooks_{user_id}`

| Property | Value                      |
| -------- | -------------------------- |
| Type     | `array` of flipbook IDs    |
| Expiry   | 1 hour (`HOUR_IN_SECONDS`) |

Caches the list of flipbook IDs a user has purchased. Generated by `get_purchased_flipbooks()` which queries order history. The cache key includes the user ID to ensure per-user isolation.

## Rewrite Endpoints

### `flipbooks`

Registered via `add_rewrite_endpoint( 'flipbooks', EP_ROOT | EP_PAGES )`. Adds the `/flipbooks/` endpoint to My Account for the purchased flipbooks tab.

## Data Flow

```
Product Edit Screen
    |
    v
save_meta_box()
    |
    +--> update_post_meta( product_id, 'r3d_flipbook_id', ... )
    +--> update_post_meta( product_id, 'r3d_preview_flipbook_id', ... )
    +--> update_post_meta( product_id, 'r3d_show_thankyou_flipbook', ... )

Product Page (Frontend)
    |
    v
render_product_flipbook()
    |
    +--> get_post_meta( product_id, 'r3d_flipbook_id' )
    +--> get_post_meta( product_id, 'r3d_preview_flipbook_id' )
    |
    +--> check_user_bought_variation_with_flipbook()  ---> HPOS-aware order query
    +--> has_active_subscription()                     ---> r3d_has_active_subscription filter
    |
    +--> show_full ? full flipbook : preview flipbook

Thank-You Page
    |
    v
change_thankyou_sub_title()
    |
    +--> get_option( 'r3d_woo_show_thankyou_flipbook' )    (global)
    +--> get_post_meta( product_id, 'r3d_show_thankyou_flipbook' )  (per-product override)
    |
    +--> Render flipbooks for each purchased item in the order

My Account > Flipbooks
    |
    v
get_purchased_flipbooks()
    |
    +--> Check transient cache
    +--> Query completed/processing orders via wc_get_orders()
    +--> Collect r3d_flipbook_id from each order item
    +--> Cache result for 1 hour
```
